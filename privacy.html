プライバシーポリシー

最終更新日: 2026年10月12日

このツールについて

asakura-uploader（以下「本ツール」）は、YouTube チャンネル「あさくら話」の運営者が、自分のチャンネルを運営するためだけに使う個人用のツールです。運営者以外の利用者はいません。

使う情報と目的

本ツールは YouTube API サービスを使い、Google の OAuth で運営者が許可した範囲で、次のことを行います。

  • 動画の投稿（youtube.upload）: 運営者自身のチャンネルへ、動画とそのタイトル・説明文・タグ・公開設定を送ります。
  • コメントへの返信（youtube.force-ssl）: 運営者自身の動画に付いたコメント（コメントとスレッドの ID、動画の ID、投稿者の表示名、本文、投稿日時）を読み込み、返信の下書きを作ります。返信は、運営者が一件ずつ内容を確認して承認したものだけを投稿します。自動の一斉返信は行いません。
  • アナリティクスの読み取り（yt-analytics.readonly）: 運営者自身のチャンネルの動画ごとの再生回数・視聴時間・視聴維持率などの集計値を読み取り、動画づくりの改善に使います。視聴者個人を特定する情報は含みません。

AI サービスの利用

  • コメントへの返信の下書きを作るため、コメントの本文と、その動画の台本を、AI サービス（Anthropic の Claude）に送ります。送ったデータは下書きの作成にだけ使います。
  • Anthropic によるデータの扱いは、Anthropic のプライバシーポリシー に従います。

保存と共有

  • OAuth の認証情報は、運営者の端末のパスワード管理ツールにだけ保存します。
  • 読み込んだコメントと返信の下書きは、運営者の端末にだけ保存し、取得から21日を過ぎたものを週1回の処理で削除します（遅くとも取得から28日以内）。コメントの ID も含めてすべて削除し、YouTube から取り直して保存し続けることはしません。
  • アナリティクスの集計値は、運営者の端末に、必要な間だけ保存します。
  • 上記の AI サービスへの送信を除き、取得した情報を第三者へ提供・販売することはありません。

許可の取り消し

本ツールへの許可は、Google アカウントの「サードパーティ製のアプリとサービス」からいつでも取り消せます。

データの削除

  • 許可を取り消した場合、または本ツールの利用を終える場合、運営者は保存している OAuth の認証情報を7日以内に削除します。
  • 許可の取り消しが分かってから30日以内に、YouTube API サービスから取得したアナリティクスの数値を削除します。
  • コメントと返信の下書きは、上記のとおり取得から28日以内に削除します。投稿した動画と返信は、YouTube Studio からいつでも削除できます。
  • ご自身のコメントのデータの削除のご依頼は、下記のお問い合わせ先から受け付け、7日以内に削除します。

YouTube と Google の規約

本ツールは YouTube API サービスを使っています。利用にあたっては YouTube 利用規約 と Google プライバシーポリシー が適用されます。

お問い合わせ

Privacy Policy

Last updated: October 12, 2026

asakura-uploader ("the Tool") is a private tool used only by the operator of the YouTube channel "Asakura Banashi" to run that channel. There are no other users.

Using YouTube API Services, within the scopes the operator authorized through Google OAuth, the Tool:

  • Uploads videos (youtube.upload): sends videos and their titles, descriptions, tags and privacy settings to the operator's own channel.
  • Replies to comments (youtube.force-ssl): reads comments on the operator's own videos (comment, thread and video IDs, author display name, text and time) and drafts replies. Only replies that the operator has reviewed and approved one by one are posted. No automated mass replies.
  • Reads analytics (yt-analytics.readonly): reads aggregate metrics for the operator's own videos, such as views, watch time and audience retention, to improve future videos. No information identifying individual viewers is included.
  • AI service: to draft replies, the comment text and the script of the video are sent to an AI service (Anthropic's Claude) and used only to create drafts. Anthropic handles this data under the Anthropic Privacy Policy.
  • Storage: OAuth credentials are stored only in a password manager on the operator's own device. Comments and reply drafts are stored only on the operator's device; items older than 21 days are deleted by a weekly job (no later than 28 days after retrieval), including comment IDs, and are not refreshed. Aggregate analytics are stored on the operator's device only as long as necessary.
  • Except for the AI service above, no data is shared with or sold to third parties.
  • Access can be revoked at any time at Google Account permissions.
  • Data deletion: when access is revoked or the Tool is no longer used, the operator deletes the stored OAuth credentials within 7 days, and deletes analytics retrieved from YouTube API Services within 30 days of learning of the revocation. Comments and drafts are deleted within 28 days as described above. Uploaded videos and replies can be deleted at any time in YouTube Studio. Requests to delete data about your own comments can be made through the contact below and are handled within 7 days.
  • By using YouTube API Services, the YouTube Terms of Service and the Google Privacy Policy apply.
  • Contact: please open an issue at GitHub Issues.
