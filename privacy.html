このツールについて

asakura-uploader（以下「本ツール」）は、YouTube チャンネル「あさくら話」の運営者が、自分のチャンネルへ動画を投稿するためだけに使う個人用のツールです。運営者以外の利用者はいません。

使う情報と目的

  • 本ツールは YouTube API サービスを使い、Google の OAuth で許可された範囲（youtube.upload）で、運営者自身のチャンネルへ動画と、そのタイトル・説明文・タグ・公開設定を送ります。
  • 他の利用者や視聴者の個人情報は、取得も保存もしません。

保存と共有

  • OAuth の認証情報は、運営者の端末のパスワード管理ツールにだけ保存します。
  • 取得した情報を第三者へ提供・販売することはありません。

許可の取り消し

本ツールへの許可は、Google アカウントの「サードパーティ製のアプリとサービス」からいつでも取り消せます。

データの削除

  • 許可を取り消した場合、または本ツールの利用を終える場合、運営者は保存している OAuth の認証情報を7日以内に削除します。
  • 本ツールが YouTube から取得したデータを保存することはありません。投稿した動画は YouTube Studio からいつでも削除できます。
  • 削除のご依頼は、下記のお問い合わせ先から受け付けます。

YouTube と Google の規約

本ツールは YouTube API サービスを使っています。利用にあたっては YouTube 利用規約 と Google プライバシーポリシー が適用されます。

お問い合わせ

お問い合わせは GitHub の Issue からお願いします。

Privacy Policy

Last updated: October 9, 2026

asakura-uploader ("the Tool") is a private tool used only by the operator of the YouTube channel "Asakura Banashi" to upload videos to that channel. There are no other users.

  • The Tool uses YouTube API Services and, within the scope authorized through Google OAuth (youtube.upload), sends videos and their titles, descriptions, tags and privacy settings to the operator's own channel.
  • The Tool does not collect or store personal information of any other user or viewer.
  • OAuth credentials are stored only in a password manager on the operator's own device. No data is shared with or sold to third parties.
  • Access can be revoked at any time at Google Account permissions.
  • Data deletion: when access is revoked or the Tool is no longer used, the operator deletes the stored OAuth credentials within 7 days. The Tool does not store any data retrieved from YouTube. Uploaded videos can be deleted at any time in YouTube Studio. Deletion requests can be made through the contact below.
  • By using YouTube API Services, the YouTube Terms of Service and the Google Privacy Policy apply.
  • Contact: please open an issue at GitHub Issues.
