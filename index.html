asakura-uploader

asakura-uploader は、YouTube チャンネル「あさくら話」の運営者が、自分のチャンネルを運営する（動画の投稿、コメントへの返信、アナリティクスの確認）ために使う個人用のツールです。一般には提供していません。

チャンネル: あさくら話

YouTube API サービスを使用しています
本ツールは YouTube API サービスを使っています。利用にあたっては YouTube 利用規約 と Google プライバシーポリシー が適用されます。

English

asakura-uploader is a private tool used only by the operator of the YouTube channel "Asakura Banashi" to run that channel (uploading videos, replying to comments after review, and reading channel analytics) through YouTube API Services. It is not offered to the public.

This tool uses YouTube API Services.
